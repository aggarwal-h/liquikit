## Usage

```tsx
"use client"

import { Dialog } from "@/components/liquikit/dialog"
```

```tsx
<Dialog.Root>
  <Dialog.Trigger>Edit profile…</Dialog.Trigger>
  <Dialog.Popup>
    <Dialog.Title>Edit profile</Dialog.Title>
    <Dialog.Description>Changes are saved to your account.</Dialog.Description>
    <Dialog.Close variant="prominent">Save</Dialog.Close>
  </Dialog.Popup>
</Dialog.Root>
```

`Dialog.Trigger` and `Dialog.Close` are glass [buttons](/docs/components/button).
