## Usage

```tsx
import { Slider } from "@/components/liquikit/slider"
```

```tsx
<Slider defaultValue={40} aria-label="Volume" />
```

The slider fills its container, and redraws its lens when the container resizes. Pass `width` for a fixed size in pixels.
