## Usage

```tsx
import { Slider } from "@/components/liquikit/slider"
```

```tsx
<Slider defaultValue={40} width={280} aria-label="Volume" />
```

The slider draws at a fixed `width` in pixels, because the lens is traced for that size. Measure the container if you need it to fill one.
