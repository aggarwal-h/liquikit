## Usage

```tsx
"use client"

import { Menu } from "@/components/liquikit/menu"
```

```tsx
<Menu.Root>
  <Menu.Trigger>Options</Menu.Trigger>
  <Menu.Popup>
    <Menu.Item>Copy</Menu.Item>
    <Menu.Item>Rename</Menu.Item>
    <Menu.Separator />
    <Menu.Item>Delete</Menu.Item>
  </Menu.Popup>
</Menu.Root>
```

`Menu.Trigger` is a glass [button](/docs/components/button). `Menu.Item` takes an `icon`.

## Examples

### Alignment

A menu opens over its trigger, with its leading edge lined up with the trigger's, so the first item lands under the pointer. Pass `align` to `Menu.Popup` to line it up by the centre or the trailing edge instead, and `side` or `sideOffset` to open it beside the trigger.
