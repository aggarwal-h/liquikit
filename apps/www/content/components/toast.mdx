## Usage

```tsx
import { Toast, useToast } from "@/components/liquikit/toast"
```

```tsx
// Once, near the root of your app
<Toast.Provider>
  <App />
  <Toast.Viewport />
</Toast.Provider>

// Anywhere inside it
const toast = useToast()
toast.add({ title: "Copied", description: "The link is on your clipboard." })
```

`Toast.Viewport` takes a `container`, so toasts can live inside a card instead of at the top of the window.
