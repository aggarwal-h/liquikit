## Usage

```tsx
import { SegmentedControl } from "@/components/liquikit/segmented-control"
```

```tsx
<SegmentedControl
  options={["Day", "Week", "Month"]}
  defaultValue="Week"
  aria-label="Range"
/>
```

It is a radio group underneath, so the arrow keys move between options.
