## Usage

```tsx
import { Meter, Progress } from "@/components/liquikit/meter"
```

```tsx
<Meter label="Storage" value={72} />
<Progress label="Downloading" value={40} />
```

Use a meter for a value within a known range, and progress for a task that is under way.
