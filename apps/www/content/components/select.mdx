## Usage

```tsx
"use client"

import { Select } from "@/components/liquikit/select"
```

```tsx
<Select.Root items={sizes} defaultValue="medium">
  <Select.Trigger aria-label="Text size" />
  <Select.Popup>
    {sizes.map((size) => (
      <Select.Item key={size.value} value={size.value}>
        {size.label}
      </Select.Item>
    ))}
  </Select.Popup>
</Select.Root>
```

Pass `items` to `Select.Root` so the trigger can show the label of the chosen value.
