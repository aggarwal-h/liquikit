## Usage


```tsx
<Popover.Root>
  <Popover.Trigger>Details</Popover.Trigger>
  <Popover.Popup>
    <Popover.Title>Refraction</Popover.Title>
    <Popover.Description>How light bends through glass.</Popover.Description>
  </Popover.Popup>
</Popover.Root>
```
